Way 1: print it with one command:

-----[ COPY START ]-----

Way 2: after "pip install cqlsh" read the yellow warning
  "The script cqlsh.exe is installed in '...\Scripts' which is not on PATH"
  That folder + \cqlsh.exe is your path.

Way 3: File Explorer:
  1. Click the address bar and type:  %LOCALAPPDATA%\Programs\Python
  2. Open your Python folder (example Python313), then Scripts.
  3. Click the address bar, press Ctrl+C, add \cqlsh.exe at the end.

If the path has spaces, put it in quotes:
  "C:\Some Folder\Scripts\cqlsh.exe"

==========================================================
 STEP 11: REPLICATION   (EXPLANATION ONLY - 3-NODE CLUSTER)
==========================================================
Real replication needs a cluster of 3 nodes. The keyspace is created
with replication factor 3, so each car record is stored as three
copies, one on each node:

        car_db -> Node 1, Node 2, Node 3

If one node goes down, data can still be read from the other two
replicas, and QUORUM (2 of 3 replicas) continues to work.

Code for a 3-node cluster (write in journal, do NOT run on 1 node):

CREATE KEYSPACE car_db WITH replication = {'class': 'SimpleStrategy', 'replication_factor': 3};
USE car_db;
CREATE TABLE cars (car_id int PRIMARY KEY, manufacturer text, type text, max_performance int, max_torque int);
INSERT INTO cars (car_id, manufacturer, type, max_performance, max_torque) VALUES (101, 'Toyota', 'Sedan', 203, 243);

Consistency rules:
  ONE    = 1 replica must respond (fastest)
  QUORUM = (RF / 2) + 1 replicas; with RF 3 that is 2
  ALL    = every replica (strongest consistency, lowest availability)

 TROUBLESHOOTING QUICK LIST
==========================================================
"cassandra.bat is not recognized"
    -> type  .\cassandra.bat -f   (with the .\ in front)

"The system cannot find the path specified"
    -> wrong folder name; type  dir  to check where you are

Crash with sigar-amd64-winnt.dll
    -> do STEP 3 (rename the DLL)

"Unable to load a default connection class" / asyncore error
    -> run:  py -3.13 -m pip install pyasyncore

"DESCRIBE ... will not work in cqlsh"
    -> use the system_schema SELECT queries in STEP 7 and STEP 8

Typed ">" or "en" instead of "ren"
    -> type only the command, no ">", and spell it fully
