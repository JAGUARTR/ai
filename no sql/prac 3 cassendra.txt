==========================================================
 STEP 11: REPLICATION (EXPLANATION ONLY - 3-NODE CLUSTER)
==========================================================
Real replication needs a cluster of 3 nodes. The keyspace is created
with replication factor 3, so each car record is stored as three
copies, one on each node:

  car_db -> Node 1, Node 2, Node 3

If one node goes down, data can still be read from the other two
replicas, and QUORUM (2 of 3 replicas) continues to work.

Code for a 3-node cluster:

  CREATE KEYSPACE car_db WITH replication = {'class': 'SimpleStrategy', 'replication_factor': 3};

  USE car_db;

  CREATE TABLE cars (car_id int PRIMARY KEY, manufacturer text, type text, max_performance int, max_torque int);

  INSERT INTO cars (car_id, manufacturer, type, max_performance, max_torque) VALUES (101, 'Toyota', 'Sedan', 203, 243);

Consistency rules:
  ONE    = 1 replica must respond (fastest)
  QUORUM = (RF / 2) + 1 replicas; with RF 3 that is 2
  ALL    = every replica (strongest consistency, lowest availability)
